# Discussion card

## Decision

State the concrete decision that needs an independent second opinion.

## Constraints

List the requirements, boundaries, prior decisions, and tradeoffs the reviewer must preserve.

## Evidence already gathered

Summarize the relevant repository evidence and name the repository-relative files the reviewer should inspect.

## Explicit questions

- Ask the specific questions that would change the decision.
- Call out assumptions or risks that need an adversarial check.

## Requested response structure

Request a self-contained Markdown opinion with a clear recommendation, supporting evidence, risks, alternatives, and concrete next steps.
